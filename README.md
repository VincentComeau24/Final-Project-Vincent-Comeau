# Animals in Space

## Project Option
Responsive Website

## Project Description
Animals in Space is an interactive educational website that explores the history of animals that were sent into space before human space exploration became possible. The website presents important animal missions through an interactive timeline where users can select different animals to learn about their missions.

## Theme Interpretation
This project responds to the Space theme by focusing on the important role animals played in the early history of space exploration. Before humans traveled into space, scientists used animal missions to study how living organisms reacted to space conditions.

## Intended User
The website is designed for students, space enthusiasts, and anyone interested in learning about the history of space exploration.

## User Goal
The user's goal is to explore a small timeline of animal space missions, learn important information about each animal, and test their knowledge by completing the interactive quiz.


# Main Features
- Space-themed landing page introducing the project
- Interactive animal mission timeline
- Clickable animal cards that display mission information
- Information modal displaying animal details and images
- Interactive quiz
- Expandable sources section
- Hover and focus feedback for interactive elements

# JavaScript Features
The website uses JavaScript to create several interactive features:
The Timeline: Users can click on an animal card to open an information window containing: animal name, mission year, image, and a quick mission description. The quiz: it can detect when users select answers and Check whether answers are correct or incorrect

# Responsive Design
Responsive features include:
- Flexible layouts using CSS Grid
- Resized images for smaller screens
- Adjusted spacing for smaller displays

# User Testing
The testers completed these tasks:
- Navigating through the website sections
- Viewing animal information from the timeline
- Completing the quiz
- Opening the sources section
The testers suggested these improvements:
- Adding more quiz questions
- Replacing placeholder images
- Adding completed sources
- Improving timeline spacing on smaller screens
- Adding scrolling animations

# Revisions
Based on user testing feedback, these were revisions made:
- Expanded Quiz Section
The original quiz contained only one question and felt incomplete. Two additional questions were added, along with improved feedback and a final score percentage.
- Added Final Images
Placeholder images were replaced with real animal and space images to make the website more visually complete and engaging.
- Added Complete Sources
The sources section was updated with real educational references used for the animal mission information.
- Improved Mobile Timeline
Spacing was adjusted so the timeline was easier to read on smaller screens.
- Added Scroll Animations
Fade-in animations one the page is opened were added to make the website feel smoother and more interactive.
